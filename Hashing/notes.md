# Hashing Notes


## Why use Hashing and where use it?

- Why use it?

Hashing is mainly used to store and retrieve information quickly.

- In my code I use it to:

Count how many times a number appears.
Count how many times a character appears.
Quickly find the frequency when a query is given.



- Where use it?

Frequency counting
Counting occurrences
Multiple queries
Finding highest/lowest frequency
Checking whether an element exists
Character frequency problems
